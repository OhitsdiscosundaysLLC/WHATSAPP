Owner Media Console

Manually send a message as yourself — not an automated reply. Every send here is logged separately from anything the bot does on its own (see the Message Vault). Sending here is never blocked by Emergency Pause, since it's an explicit action you're taking, not automation.

The Owner Media Console requires Supabase to be configured.

See docs/DEPLOYMENT.md for setup.
