Moderation

Deterministic moderation only (banned phrases, repeated-message spam, link detection). Destructive actions (delete a message, remove a participant) require an explicit second switch below — never implied by Moderation being on.

Create and manage moderation rules from the Rules tab (rule type: "Moderation").

Deleted-Message Archive

Only "delete for everyone" is observable by WhatsApp's protocol — "delete for me" can never be detected or recovered, by this bot or any other. Requires Monitoring to also be on.

Commands

Available only to numbers configured in OWNER_WHATSAPP_NUMBERS / ADMIN_WHATSAPP_NUMBERS (set on the server), sent as a message inside this group. Normal participants cannot use these. 

.bot on|off       Turn the bot on/off for this group
.ai on|off        Turn AI on/off for this group
.ai <question>    Ask AI directly (requires AI on)
.rules            List this group's rules
.settings         Show this group's current configuration
.status           Quick status summary
.help             This list

WhatsApp sometimes presents a sender as an @lid (linked-id) JID instead of a phone-number JID. The bot resolves this automatically — a configured owner/admin number is recognized either way, as soon as WhatsApp has associated that person's @lid with their phone number (this happens automatically during group discovery, or the first time that person sends a message carrying both forms).
